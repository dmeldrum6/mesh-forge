How it works
MeshForge runs your pasted code with access to THREE (r128). Your code must assign a value to a variable named result. It can be: • THREE.Group — multiple meshes (recommended for complex objects) • THREE.Mesh — a single mesh • THREE.BufferGeometry — raw geometry (gets auto-wrapped) Each mesh in the group becomes a separate scene object, preserving its position, rotation, and scale so you can transform parts independently. Materials are preserved for preview but normalized to MeshPhongMaterial for OBJ export compatibility.

Create a [OBJECT] using Three.js r128 geometry primitives. Rules: - Use only built-in Three.js geometries (BoxGeometry, CylinderGeometry, SphereGeometry, ConeGeometry, TorusGeometry, etc.) - Combine all parts into a THREE.Group assigned to a variable called result - No import statements, no render loops, no scene/camera/renderer setup - Position parts relative to the group's origin (0,0,0) - Use THREE.MeshPhongMaterial for materials - Keep the overall size roughly within a 4×4×4 unit bounding box Example structure: const result = new THREE.Group(); const bodyGeo = new THREE.CylinderGeometry(0.5, 0.6, 2, 16); const bodyMat = new THREE.MeshPhongMaterial({ color: 0x888888 }); const body = new THREE.Mesh(bodyGeo, bodyMat); result.add(body); // ... more parts ...
Code is executed locally in your browser. Only THREE is in scope.
